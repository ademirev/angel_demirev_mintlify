## A Note on This Application Itself

Building this as a Mintlify docs site was intentional. It's not a gimmick — it's a way of doing several things at once.

First, it meant actually using the product. Mintlify serves 100M+ developers a year and powers the documentation for Anthropic, Microsoft, Spotify, and Coinbase, among others. I wanted to understand what that experience is like from the inside before I walked into a conversation about building the team that supports it.

Second, it's a demonstration of builder mindset. I've built data warehouses, ETL pipelines, API integrations, and automations at every company I've worked at. Writing a PDF and submitting it through Ashby is fine, but it doesn't show you anything about how I think. This does.

Third, it's just more navigable. A structured, searchable docs site with clear sections is a better reading experience than a wall of text in a PDF. If Mintlify's thesis is that documentation should be beautiful and useful, the application should reflect that.
